Secret or otpauth link

Base32 uses the letters A to Z and the digits 2 to 7 only; the digits 0, 1 and 8 never appear in a secret. Spaces and hyphens are ignored. An otpauth://totp/ link sets the digits, period and algorithm for you.

Use this file offline

  1. Save this file to disk. It is one HTML file with no companions: no scripts to fetch, no fonts, no images.
  2. For an exchange or email secret, copy it by USB stick to a computer that does not go back online. A spare laptop with the radio off is enough.
  3. Turn the wifi off or unplug the cable. The banner at the top of this page turns green when the browser reports no network.
  4. Open the file by double clicking it. The address bar should read file:// and nothing should load from anywhere.
  5. Type or paste the secret. Codes appear immediately and keep rolling every 30 seconds.
  6. Close the tab when you are done, then reconnect. Unless you chose to save an entry, nothing is written anywhere: no cookies, no storage, no history of what you typed. Saved entries stay in this browser's local storage until you remove them or the browser's data is cleared.

The banner reads navigator.onLine, which only tells you whether the browser can see a network interface. It is a reminder, not proof of isolation. Pulling the cable or switching the radio off is the proof.

What this file is honestly good for

A time based code is a shared secret plus a clock. Whoever holds the secret can make codes forever, so a secret sitting on the same computer you log in from is no longer a second factor: it is a second copy of the first one. Treat this as a recovery aid. The everyday code should still come from a phone or a hardware key you keep separate from the machine you type your password into.

The good use is the one nobody plans for. Your phone is lost, wiped or dead, the exchange wants a code, and the only thing you still have is the backup of the setup secret you wrote down when you enrolled. This file turns that backup into codes without asking any website for help, and without installing anything.

No legitimate service ever asks for your TOTP setup secret. They ask for a six digit code. A page asking you to paste the secret itself, or to scan your enrollment QR code into their site, is stealing the second factor outright.

If the codes are rejected

Nine times out of ten it is the clock. TOTP divides real time into 30 second windows, so a machine whose clock has drifted by a minute produces codes for the wrong window. An offline computer drifts faster than a connected one because nothing corrects it. Set the clock offset in the code card until the device time shown there matches real UTC, and try again. Most servers accept the window either side of their own, so being within 30 seconds is usually enough.

The other cause is a mistyped secret. Base32 has no 0, 1 or 8, so a handwritten O is the letter O, a written l is probably the letter I or the digit 7, and a B is never an 8. If the secret is the wrong length the tool says so.

This file computes codes with the browser's own WebCrypto (HMAC per RFC 2104, SHA-1, SHA-256 or SHA-512, truncated per RFC 4226 and clocked per RFC 6238). It carries the published RFC 6238 test vectors and RFC 4648 base32 vectors and checks itself on every load; if any vector fails it refuses to display a code. It declares a content security policy that forbids the browser from making any network request at all. From OpenBitcoin.com, page openbitcoin.com/tools/2fa. Never type a seed phrase, a private key or an xprv into anything, including this file: it has no use for one and no field for one.
